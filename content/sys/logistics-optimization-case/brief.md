# Logistics optimization system

A regional distributor ships palletised goods from four depots, A to D, to six delivery zones every day. Orders
are known by the evening. Each night the planners decide which depot serves which zone for the next day, and how
many trucks go on each route between them. Dispatchers then sequence the stops within each zone.

Today the nightly plan is built by hand, from experience. Management believes a better plan would cost less, but
the plan must also be on time and stable enough for dispatchers to trust and load against.

How would you build a system that produces the nightly plan, and how would you show that the plan is good?
