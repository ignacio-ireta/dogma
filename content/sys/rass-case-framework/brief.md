# Bike-share rebalancing

A city bike-share operator runs 900 stations. In the evening peak, about one station in six is empty
at any moment, and each empty hour loses trips the rider would otherwise have taken. Trucks move bikes
between stations by hand, and the dispatcher chooses stations from experience.

The operator asks whether a model can tell the dispatcher which stations will run empty in the next
two hours. Walk us through how you would approach it.
