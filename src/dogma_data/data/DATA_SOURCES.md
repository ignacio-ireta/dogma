# Data sources for dogma_data

Every file in this directory is either copied byte-for-byte from `sources/` in this repository,
or is a bundled dataset read from an installed library. Nothing here is downloaded at run time.
Checksums: `tests/unit/dogma_data/test_catalog.py` compares each vendored CSV with its source.

### What is deliberately messy in the interview-prep files

These are not cleaned. The mess is the point of the pandas and SQL exercises.

- `customers`: 50 repeated `customer_id` values; `gender` with casing variants (`m`, `f`), a
  blank value and missing values; `plan_type` with casing variants (`basic`, `PREMIUM`);
  `age` with missing values and impossible values (-1, 0, 150); `annual_income` is lognormal with
  200 missing values; `signup_date` with malformed values (`not_a_date`, `2025/13/01`, `N/A`,
  blanks); `monthly_spend` with missing values; `churned` is imbalanced (6.1% positive, measured; the generator's comment says about 15%).
- `orders`: `amount` is lognormal (right-skewed) with 300 missing values (returns and
  cancellations); `customer_id` values are drawn from the customer ids; dates are strings.
- `surveys`: `satisfaction_score` and `nps_score` have missing values; customers are sampled
  without replacement.

## Bundled datasets (no file here)

Loaded from the installed libraries with no network access.

| Ids | Library | Licence |
|---|---|---|
| `iris`, `wine`, `breast_cancer`, `diabetes`, `digits`, `linnerud` | scikit-learn (`sklearn.datasets`) | BSD-3 for the packaging, as distributed with scikit-learn. Underlying data: Fisher (1936) and Anderson for iris; UCI for wine and breast cancer; Efron et al. | `longley`, `stackloss`, `engel`, `macrodata`, `co2`, `sunspots`, `nile`, `elnino` | statsmodels (`statsmodels.datasets`) | Public domain, per each dataset's `COPYRIGHT` string in statsmodels ("This is public domain", and "This data is in the public domain" for `elnino`). |

Statsmodels datasets are read through `statsmodels.datasets.<name>.load_pandas()`. The package
`statsmodels.api` is never imported, because it is slow.
