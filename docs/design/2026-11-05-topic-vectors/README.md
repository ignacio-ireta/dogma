# Hand-authored topic vectors

Open `index.html` in a browser for an offline gallery of the 21 production scenes: 20 subject
motifs and one general study motif. This is a review snapshot rendered from the React components,
not an application dependency. All illustrations remain SVG in the gallery.

The editable source and maintenance notes live in
[`web/src/components/illustrations`](../../../web/src/components/illustrations/README.md).
Exercise pages use a smaller composition with a single presenter; Today uses the full scene and
its active topic. Related topics intentionally share subject motifs.
