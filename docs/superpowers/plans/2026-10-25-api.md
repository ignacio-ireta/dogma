# HTTP API v1 Implementation Plan (I-14)

> **For agentic workers:** test-first. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Expose the CLI's services as a loopback-only, versioned FastAPI API (RFC 9457 errors,
OpenAPI contract for I-15).

**Architecture:** `create_app(settings)` returns a FastAPI app. Thin routers call `services/`,
which call existing domain functions (no logic re-implemented). Domain codes map to
`application/problem+json`. A pure-ASGI guard checks Host, Origin and body size before routing.

## Endpoints (`/api/v1`; request and response are Pydantic models)

| Method, path | Request | Response | Errors |
|---|---|---|---|
| GET `/health` | - | `{status, version}` | - |
| GET `/catalog` | - | `CatalogOut` from `var/catalog.json`, else built in memory | 500 schema |
| GET `/topics/{id}` | - | `TopicOut`: lesson md, meta, card count, problems | 404 |
| GET `/problems/{id}` | - | `ProblemOut`: problem md, meta, starter, hints count | 404 |
| GET, PUT `/workspace/{id}` | `{content}` ≤ 256 KiB | `WorkspaceFile {exists, content}` | 404, 413, 422 |
| POST `/attempts` | `{problem_id, mode: run\|submit}` | 201 `{report, recorded, record_warning}` | 404, 409 no file |
| GET `/attempts/{id}` | - | `AttemptRecord` (stored row) | 404 |
| GET `/today?energy=normal\|low` | query | `TodayOut`: resume or plan, last note | 422 |
| POST `/sessions/{id}/close` | `{stopped_where, next_step, blocker?, answer?}` | `CloseOut` | 404, 422 |
| GET `/reviews/due?limit=1-100` | query | `{enrolled, cards[]}` (syncs cards, as `dogma review`) | 422 |
| POST `/reviews/{card_id}` | `{rating 1-4, expected_due, expected_content_hash}` | `ReviewOut` | 404, 409 |
| GET `/progress?week=N` | query | `ProgressOut`: weeks, topics, summary | 404 week |
| GET `/search?q&topic&limit=1-100` | query | `SearchOut` (cited hits) | 503 no index |
| POST `/tutor/hint` | `{problem_id, level 1-4, confirm_walkthrough}` | `HintOut`: reviewed hint + nudge | 403, 503 |
| POST `/tutor/debug` | `{problem_id}` | `TutorAnswerOut` | 409, 503 |

## Decisions (flagged for the coordinator)

- **Synchronous grading and tutor.** ENGINEERING_STANDARDS §8 says no request blocks over 30 s.
  Every problem has `timeout_s: 30`, so grading is bounded. The local tutor measured 33-42 s
  (ROADMAP I-12), so `/tutor/*` can exceed the rule. v1 is plain JSON, as briefed; SSE or a job
  model is needed before I-15 relies on it.
- **Recording** follows the CLI rule: only the workspace file is graded, so it records when
  `settings.record_attempts` is on. A storage failure keeps the grade (201, `recorded: false`).
- **Reuse.** Calls go through `dogma.cli.attempts.grade_attempt` (the test seam),
  `dogma.cli.resolve` and `dogma.cli.path_view`. Those helpers belong in `content/`;
  `serve` imports the API lazily to avoid a cycle.
- **Settings is not edited.** CORS origins come from `create_app(allowed_origins=...)` and
  `dogma serve --allow-origin`, default `http://127.0.0.1:5173`.
- **No Swagger/ReDoc**: their assets load from a CDN; the app must work offline.

## Security

- `dogma serve` refuses non-loopback hosts (exit 2) before importing or binding anything.
- Host must be a loopback name (DNS rebinding); an Origin, when present, must be allowed.
  Both refusals are 403 `API_REQUEST_REFUSED`. CORS never uses a wildcard or credentials.
- Request bodies ≤ 1 MiB (413); workspace content ≤ 256 KiB.
- Ids are shape-checked, then resolved under `content/` or `workspace/` only; bad ids are 404.
- Responses never include `solution.py`, `test_*.py` or hint text (only `hints_count`).
- Every `ErrorCode` and `StorageErrorCode` has a `STATUS_BY_CODE` row (test-enforced); unexpected
  failures are 500 `API_INTERNAL_ERROR` with no traceback.

## Files

- Create: `src/dogma/api/` (app, errors, middleware, deps, ids, openapi; `schemas/`,
  `services/`, `routers/`), `src/dogma/cli/serve.py`, `tests/unit/api/`, `tests/e2e/api/`.
- Modify: `src/dogma/cli/main.py` (one registration), `src/dogma/core/errors.py` (10 `API_*`
  codes), `pyproject.toml` and `uv.lock` (`fastapi`, `uvicorn` only).

## Tests (default suite, scratch `Settings(repo_root=tmp_path)`)

- App: OpenAPI path snapshot and determinism; no docs; Host, Origin, CORS; body limit.
- Errors: status table; validation names fields without echoing input.
- Each resource: happy path, unknown and traversal ids, stale and not-due reviews, recording
  off, storage failure, locked walkthrough, down model. One `integration` test runs the real
  grader on the reference solution.
- `serve`: non-loopback refused without starting uvicorn; URLs printed; port range.
- E2E (`-m e2e`): one learner day: catalog, save, submit, today, close, review, progress.

## Review focus

- Nothing reaches outside `content/` or `workspace/`; ids pass the shape check first.
- Recording matches the CLI; a database failure never changes the verdict.
- A failing solution is a 201 with status data, never a 5xx; errors never echo tracebacks.

## I-23 addendum: layering, tutor SSE, coverage

Status: implemented. Where this addendum and the text above differ, this addendum wins.

- **Layering.** The API no longer imports `dogma.cli`. The helpers it used moved to shared modules:
  `content/resolve.py` (ProblemRef, Target, resolve_problem, resolve_target, workspace_file),
  `learning/path.py` (READY, TopicRow, current_week, topic_row), `runner/attempt.py` (grade_attempt),
  and `content/coverage_scope.py` (scope_syllabus, read_packages). `cli/resolve.py` is deleted.
  `cli/path_view.py` keeps the `dogma path` command. `cli/attempts.py` keeps only `record`, the CLI's
  warning printer. The CLI callers import the new modules.
- **Grade seam.** The seam is `dogma.runner.attempt.grade_attempt`, called as a module attribute at
  call time. Tests patch that name (`tests/unit/api/conftest.py`, `tests/unit/cli/conftest.py`).
- **Contracts** (pyproject `[tool.importlinter]`): "API never imports the CLI"; "Domain packages never
  import the CLI or the API" (content, learning, runner, grading, tutor, corpus, db).
- **Model dependency.** `api/deps.py` has `get_model` (the loopback `LocalModel`, built per call so a
  refused URL is still logged by the gateway) and `get_gateway(settings, model)`. Tests replace the
  model with `make_client(model=...)`.
- **SSE, ADR-0017.** The gateway has no streaming entry point and `tutor/` is not edited, so the stream
  routes wrap the public `LLMProvider.stream()` in a relay provider that the ordinary `Gateway` calls.
  The gateway still does the call log, the loopback check and the reasoning strip. The relay forwards
  each delta as it arrives, and the call runs on a worker thread (`api/streaming.py`).
- **Event protocol** (`text/event-stream`, one JSON data line per event):
  - Hint, `POST /tutor/hint/stream`: `reviewed` `{level, reviewed, hints_note}` first, before any model
    call; then `nudge` `{text}` (raw deltas); then exactly one terminal event.
  - Debug, `POST /tutor/debug/stream`: `answer` `{text}` deltas, then exactly one terminal event.
  - Terminal events: `done` (hint: the `HintOut` JSON; debug: the `TutorAnswerOut` JSON, so it is the
    same answer as the JSON route); `unavailable` `{code, note}` when the model is down (the reviewed
    text stands); `error` (an RFC 9457 problem) for any other failure after the stream has started.
  - Before the stream starts, errors are JSON problems with the JSON route's status: 403 L4 lock, 404,
    409 no failing attempt, and 503 for a refused endpoint on debug. A refused endpoint on hint comes
    after `reviewed`, as an `error` event, as the CLI does.
  - A reply that is only reasoning, or empty, on hint with a reviewed hint, is a `done` with
    `nudge: null` and a `nudge_note`, as on the JSON route. On debug it is an `unavailable` event.
- **Guard semantics.** The streamed deltas are raw (reasoning blocks hidden). The verdict, ceiling and
  long-code guards and the unsourced note run on the final text, which is what `done` carries. The
  client replaces the streamed text with `done` (`done.nudge.text` for hint, `done.text` for debug), or
  clears it when there is no nudge. The guards are not re-implemented.
- **Coverage.** `GET /api/v1/coverage?tier=A|B|C&track=<code>`: `by_track` (with `title`), `by_tier`
  (always A, B and C), `rows` (topic rows, only when `tier` or `track` is given, otherwise null), and
  `unreadable_topics` (topic ids whose package does not load; not counted). An unknown track is 404,
  a malformed track or tier is 422.
- **Open.** `cli/coverage_view.py` still has its own copy of the scoping and package loading, because
  that file was not on this increment's list. It should use `content/coverage_scope.py`. The lazy import
  comment in `cli/serve.py` (a cycle with the API) is stale. The lazy import is still worth keeping for
  start-up time, but the reason it gives is gone.
