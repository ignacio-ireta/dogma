# Tutor v0 Implementation Plan (I-12)

> **For agentic workers:** Implement task-by-task, test first. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `dogma hint` and `dogma debug` answer from a local model with citations, bounded
context, versioned prompts and a call log. The rest of the app works when the model is down.

**Architecture:** `dogma.tutor.gateway` is the only path to a model. It validates the endpoint,
uses the `local` (httpx, OpenAI-compatible) or `fake` provider, enforces timeouts, and appends one
metadata line per call. Evidence comes from content, the workspace, recorded attempts and the
corpus index. A budget assembles the prompt.

**Tech stack:** Python 3.12, httpx (new), Pydantic v2, Typer, Rich, the existing db session,
`dogma.corpus.index.search`.

**Spec:** ARCHITECTURE §4.5, ENGINEERING_STANDARDS §10 and §6, LEARNER_PROFILE §7, ADR-0007/0008.

## Global constraints

- Only `dogma.tutor.gateway` talks to a model. Only `providers/local.py` imports httpx.
- Loopback only (`127.0.0.1`, `::1`, `localhost`), checked before any socket. No external provider.
- Timeouts: connect 3 s, first token 60 s, total 180 s.
- Prompts never include `private/`, the learner profile, `solution.py`, test files or hidden values.
- The tutor never states that code is right or wrong. Output guards enforce it.
- `var/llm_calls.jsonl` holds metadata only: no prompt or answer text.

## Interfaces

- `LLMProvider(Protocol)`: `name`, `complete(req) -> CompletionResult`, `stream(req)`.
- `Gateway(settings, provider=None).complete(CallMeta) -> CompletionResult`; failures are
  `DogmaError` subclasses with an outcome for the log.
- `hint(settings, target, *, level, yes, ask, gateway)`; `debug(settings, target, *, gateway)`.
- L4 opens after 2 recorded submits that did not pass (`failed`, `error`, `timeout`, `oom`), or on
  confirmation (`--yes`, or an answered yes).

## Test list (RED first, then GREEN)

1. Loopback accepts the three hosts and refuses LAN, public, credential and malformed URLs.
2. Local provider: payload, timeouts, SSE, usage, `<think>` stripping, failure mapping, deadline.
3. Gateway: one line per call; no prompt body; refusals and failures logged; unwritable log error.
4. Prompts: version and mode front matter; golden snapshots for hint L1–L4 and debug.
5. Context: token budget, deterministic truncation, tags, redaction of hidden messages.
6. Evidence (real temp DB): failed count, latest report rebuilt, degraded inputs, no sentinels.
7. Service: L4 lock, citation and verdict guards, debug code omission, degradation.
8. CLI: output, levels, `LLM_UNAVAILABLE` one line, lock prompt, usage errors, help examples.
9. `@pytest.mark.llm` smoke, deselected by default.

## Review focus

- No path reads `private/`, solutions, hidden tests or the profile into a prompt.
- Loopback cannot be bypassed by URL tricks or by building a provider directly.
- Log lines never hold prompt or answer text, and failed calls are still logged.
- Context stays under about 12K tokens; golden diffs are read before acceptance.

## I-22 addendum: tutor grounding

Status: implemented in `src/dogma/tutor/` and `src/dogma/cli/tutor.py`. Where this addendum and the
text above differ, this addendum wins for levels 1 to 3.

- **Authored hint first.** `dogma hint PROBLEM --level N` (N = 1 to 3) reads the problem's
  `hints.md` (`tutor/hints.py`). Both heading forms are accepted: `## Hint N: label` and
  `## Hint N — label`. The reviewed `## Hint N` section prints before any model call, so it works
  when the model is down. Lower levels are named, not shown.
- **Grounded nudge.** The model then writes a nudge on the learner's code (`hint.md` v3). The reviewed
  hints up to N are its ceiling. They are citable sources (kind `reviewed`), and levels above N are
  never sent to the model. The TASK line and the L1–L3 sections say so, and each nudge ends with one
  question.
- **Degradation.** A down model, or an empty answer, skips the nudge with one note: "Personalised nudge
  needs the local model". The command exits 0. A refused non-loopback URL still exits 1, a
  configuration error, after the reviewed hint has printed. A missing or malformed `hints.md` gives the
  I-12 model-only answer with a note, and a down model is then `LLM_UNAVAILABLE` with exit 1. L4 is
  unchanged: model-generated and locked.
- **Ceiling guard** (`tutor/ceiling.py`). At L1 and L2, a sentence is removed when its formula appears
  only in a later level, and a note says a formula was left out. The rule and its limits are in that
  module. A formula the problem statement already shows is never held back.
- **Corpus dedupe.** Evidence keeps 12 candidate passages. Context assembly keeps at most one per source
  document and at most 4 (`select_corpus`).
- **Eval.** `tests/unit/tutor/test_grounding_eval.py` holds hand-graded scripted rows and two service
  runs with the fake provider. Golden snapshots: hint v3 (L1 to L3 changed, L4 header only); debug
  unchanged.
- **Known limits.** The guard judges formulas only, not prose. A nudge that paraphrases a later hint
  without a formula gets through. The quality of a live nudge is checked by hand, not by this eval.
