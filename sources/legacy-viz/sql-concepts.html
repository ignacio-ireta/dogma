SELECT * FROM employees WHERE bonus IS NULL;

Returns rows 2, 4 (Bob, Dave) — correct way to check for NULL

SELECT * FROM employees WHERE bonus = NULL;

Returns no rows! — NULL = NULL evaluates to NULL (falsy)
