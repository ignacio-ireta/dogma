Accuracy measures overall correctness. Precision answers "of those predicted positive, how many were right?" Recall answers "of all actual positives, how many did we find?" F1 balances precision and recall.

Separability controls how well the model distinguishes classes. Higher separability → the two class distributions are farther apart → higher AUC.

Log Loss (Cross-Entropy)

Log loss heavily penalizes confident wrong predictions. See how the penalty grows as confidence increases in the wrong direction.

Log Loss
0.22
Log Loss = −[y·log(p) + (1−y)·log(1−p)]

When the actual label is positive (y=1), log loss penalizes low predicted probabilities. When actual is negative (y=0), it penalizes high predicted probabilities. The penalty grows exponentially as confidence in the wrong answer increases.
