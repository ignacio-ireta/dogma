Central Limit Theorem

No matter the source distribution, the distribution of sample means approaches normal as sample size increases.

Source Distribution
Sampling Distribution of Means
The Central Limit Theorem states that the distribution of sample means approaches a normal distribution as sample size increases, regardless of the shape of the source distribution. The mean of the sampling distribution equals the population mean, and its standard deviation equals σ/√n.

Hypothesis Testing & p-values

Drag the test statistic to see how p-values change. The shaded area is the probability of seeing this result (or more extreme) if the null hypothesis is true.

Two-tailed test (vs one-tailed)
p-value = probability of seeing this result (or more extreme) IF the null hypothesis is true. A small p-value means the data is unlikely under the null hypothesis.
p-value does NOT tell you the SIZE of the effect, nor the probability that the null hypothesis is true. It only tells you how surprising the data would be if the null were true.

Confidence Intervals

Run many experiments to see that ~95% of 95% confidence intervals contain the true parameter.

A 95% confidence interval means: if we repeated this experiment many times, about 95% of the intervals would contain the true parameter. It does NOT mean there is a 95% probability the true value is in this particular interval.

Power Curve: How Power Changes with Sample Size
Type I error (false positive): concluding there is an effect when there isn't one. Type II error (false negative): failing to detect a real effect. Statistical power = 1 − P(Type II error) = probability of detecting a real effect.

Correlation vs Causation

A strong correlation does not imply a causal relationship. Explore spurious correlations and confounding variables.

Correlation does not equal causation. To establish causality, consider: A/B tests (randomized experiments), instrumental variables, difference-in-differences, or regression discontinuity designs.
